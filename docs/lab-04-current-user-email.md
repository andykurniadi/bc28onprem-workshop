# Lab 4: Configure current-user Microsoft 365 email

## Goal

Configure Business Central to send mail as the currently signed-in user.

## Steps

1. Open **Set Up Email** in Business Central and choose **Microsoft 365**.
2. Enter the client ID and client secret from the Entra application registration.
3. Verify the registration and complete interactive sign-in and consent as the user.
4. Finish the setup and send a test email.

The user must have a valid Exchange Online mailbox and permission to send from the selected address. This scenario uses the delegated Microsoft Graph permissions from Lab 2.
